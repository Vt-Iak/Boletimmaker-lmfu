Observações de revisão

Aparecem só no editor, nunca no PDF. Para comentar um trecho, selecione o texto na página e use na barrinha; para um bloco, use o mesmo ícone na barra do bloco.

Fontes da edição
Rodapé de fontes (verso)

Simples: "[1] Veículo · Título · data · site". O rodapé do verso é montado a partir desta lista; na notícia aparece só o selo "[n] Veículo · data", com o link.

Canais de referência

Veículos que o boletim cita, válidos para todas as edições. Ao colar um link numa fonte, o veículo é preenchido pelo canal do domínio. O número antes do nome é a prioridade na Pauta; "Coleta" envia os canais validados para a busca automática.
